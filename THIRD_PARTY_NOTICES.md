# Third-party notices

## City lookup

City search uses the Open-Meteo Geocoding API and GeoNames location data.
No location database is bundled. Attribution is also displayed in the settings editor.

- API: https://open-meteo.com/en/docs/geocoding-api
- Location data: https://www.geonames.org/ (CC BY 4.0)

`tools/xiaomi_onboarding.py` implements the Xiaomi QR and encrypted cloud API
flow based on these MIT-licensed projects:

- `mihome-ctl`, Da-Wei Lee: https://github.com/daviddwlee84/mihome-ctl
- `Xiaomi-cloud-tokens-extractor`, Piotr Machowski:
  https://github.com/PiotrMachowski/Xiaomi-cloud-tokens-extractor

Their copyright notices are retained below. MijiaLamp does not bundle either
package or establish a runtime dependency on them.
